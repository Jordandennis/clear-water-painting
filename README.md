# Clear Water Painting
![Clear Water Painting logo, created by Kylea Archer](./images/Clear_Water_Painting-A_edited.png)

## Purpose
Main landing page for Clear Water Painting based in Courtenay, British Columbia

## Current State
The page is currently not in active development. Development is slated to continue following the completion of the Node.js tutorial located [here](https://nextjs.org/learn), the (inappropriately named) reposotiry for which can be found [here](https://github.com/Jordandennis/nodejs-tutorial).

## Plan
React will be the primary framework used and will be hosted on either Vercel or directly on AWS using an EC2 instance

## Development History
### Wix
Orginally, the company utilized Wix's platform to create, host, and advertise the web page on Google. It was found that the platform was cost prohibitve for the long term hosting of a small, seasonal company's landing page. Furthermore, there was a desire for increased felixibility and control of both the front end, back end, and connective powers of the app without being dependent on a third party platform
